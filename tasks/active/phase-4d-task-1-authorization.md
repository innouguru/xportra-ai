- **Planning basis:** [ADR-0017](../../docs/decisions/ADR-0017-regulatory-knowledge-administration.md), accepted for planning only.
- **Task sequence:** [Phase 4D.10 plan](../../docs/phases/phase-4d-regulatory-knowledge-administration.md).

## Decision requested

Explicitly authorize the bounded Task 1 — Finalize implementation contracts
and unresolved decisions — from the Phase 4D.10 plan. This authorization,
if provided, applies only to Task 1. It does not authorize Tasks 2–11,
runtime implementation, migrations, production or infrastructure changes,
or exporter-facing publication.

Task 1 must retain the eight Phase 4D.7 directions and document the owners,
evidence, resolution, or explicit deferral for each open technical choice.
Qualified product/classification, route/BCP, plant-health, Nigerian-source,
and shipment-applicability questions remain separate gates. No legal finding,
technical decision, paid service, or publication approval is inferred.

Until explicit authorization is received, do not begin Task 1 or any later
Phase 4D task.
